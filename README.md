
# ♻️ Smart Waste Management System

## Project Description
An IoT-based smart waste management system that monitors dustbin levels and helps garbage collection teams locate full dustbins using GPS.

## Features
- Smart dustbin monitoring
- SMS alerts using GSM
- GPS location tracking
- Interactive map
- Driving route
- Distance calculation
- Green dashboard interface

## Hardware
- Arduino UNO R3
- SIM900A GSM Module
- NEO-6M GPS Module
- Ultrasonic Sensor
- Moisture Sensor
- Servo Motor

## Software
- Arduino IDE
- Python
- Streamlit
- Folium
- OpenStreetMap

## Run the Dashboard

Install the required packages:

pip install -r requirements.txt

Run the application:

streamlit run app.py

## Deployment
Deploy this GitHub repository through:

https://share.streamlit.io/

Main file path: app.py
